# Drawing particle evidence

The Unity `level4` GameObject `ScriptedParticleSystem` has `ParticleEffectManager` component 1667. Its serialized lists `particleColorForColorsSecondary` and `particleColorForColorsPrimary` each contain the same 56 colors, in selected-color order; these colors differ slightly from the displayed palette for some entries. `ParticleEffectManager.wi` (0x1569cc8) indexes the relevant list using the current brush/color selection for non-eraser brushes, then multiplies RGBA by 0.75. `wh` (0x156956c) sets the particle system's start color from the two color-list results. `DisplayParticles.Update` (0x15691b0) checks Unity `Input.GetMouseButtonDown(0)` and calls `wg`, which invokes `wh`; this establishes color setup on press, not the complete emission trigger or particle dynamics.

The web removes its invented random stars during pointer movement and retains its existing burst on release, as requested. For drawing and fill it uses the extracted particle list and 0.75 RGB/alpha multiplier. Web burst count, timing and physics remain an approximation, and the original emission conditions have not been fully decoded. Original saved metadata can be read from `level4` component 1667: its five serialized lists start at offset 44; the final two contain the colors used for the color palette. RGB values in `web/src/particleColors.ts` are rounded to eight bits.
